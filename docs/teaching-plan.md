# 教学安排建议

## 目标学生

适合机器人、嵌入式、智能控制、强化学习方向的本科高年级或研究生实验。

## 建议课时

| 阶段 | 内容 | 产出 |
| --- | --- | --- |
| 第 1 次 | 项目结构导读 | 学生能说明硬件、运行时、训练三仓关系 |
| 第 2 次 | BOM、结构件、扩展板 | 学生能读懂物料和装配风险 |
| 第 3 次 | Uno Q 运行时 | 学生能解释 Linux 50 Hz 与 MCU 100 Hz 的分工 |
| 第 4 次 | 舵机 ID 与校准 | 学生能完成单舵机 ID 写入和零位概念说明 |
| 第 5 次 | Web UI 与安全状态机 | 学生能解释 torque off、default pose、walk、get up |
| 第 6 次 | RL 训练环境 | 学生能启动一个训练任务或读懂训练命令 |
| 第 7 次 | ONNX 导出与部署 | 学生能把 checkpoint 导出为 ONNX 并说明部署位置 |
| 第 8 次 | 实机联调与答辩 | 学生展示复现记录、风险控制和改进方案 |

## 推荐作业

1. 画出 Host、MCU、舵机、IMU、Web UI 的数据流图。
2. 从 BOM 中挑 5 个关键物料，说明替代选型风险。
3. 解释为什么训练放服务器、推理放板端。
4. 解释为什么 Jetson Nano 不能直接替代 Uno Q。
5. 导出一个 ONNX 模型并说明输入输出维度。

## 评分建议

| 项目 | 权重 |
| --- | --- |
| 项目结构理解 | 20% |
| 硬件与安全意识 | 20% |
| 运行时部署能力 | 25% |
| 训练与模型导出理解 | 25% |
| 复现实验记录 | 10% |

## 实验室安全提示

- 所有 torque on 操作必须有人看护。
- 初次行走建议使用保护架或手扶。
- 舵机 ID 设置阶段一次只接一个舵机。
- 电池供电调试前先用限流电源验证。
- 训练与部署模型要做版本记录，避免不知道实机跑的是哪一个模型。
